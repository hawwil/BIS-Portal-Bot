# BIS Portal Bot

بوت تلغرام بيبعت لأولياء أمور طلاب BIS غزة أي واجب أو علامة أو إعلان جديد على بوابة الطالب.

- كل بيانات الطلاب (كلمات السر، الواجبات، العلامات) محفوظة **مشفّرة** بملف `state/data.enc`، والمفتاح موجود بس بالـ Secrets.
- الفحص كل نص ساعة من ٦ الصبح لـ ١٠ بالليل بتوقيت غزة.
